# Job Aid: Generate an Inspector's Report

Audience: Admin/office users

Goal: Export a pesticide application report for a selected date range.

## Before you start

- Applications must be recorded.
- Applicator information should be entered.
- Treatment products should include correct product/EPA information.

## Steps

1. Open the app.
2. Choose **Office Mode**.
3. Open **Reports**.
4. Select **Licensing Inspector**.
5. Choose:
   - **Start Application Date**
   - **End Application Date**
6. Review application count and chemical record count.
7. Review the report table.
8. Review **Printable Report Preview**.
9. Download:
   - **Download Printable Report**
   - **Download Inspector CSV**

## Printing

1. Click **Download Printable Report**.
2. Open the `.html` file.
3. Print from the browser.

## Troubleshooting

- No records: check date range and confirm applications were completed.
- Missing chemicals: check treatment chemical assignments.
- Missing applicator: check applicator setup and completion entry.
